# MANTIS
## Multi-dimensional Advanced Neural Temporal Interpretation System

### What are we doing:
Analyze patterns in point cloud motion using machine learning

### Why we're different
MANTIS is about representing motion data as a 2D images, and applying proven convolutional [and other] neural networks, with the purpose of finding patterns in motion data. This image representation allows us to harness the power of state-of-the-art convolutional neural networks, like YOLOv5 and SAM, which have proven incredibly effective in various image recognition tasks. This eliminates the need to develop specialized models from scratch, allowing MANTIS to benefit from the continuous advancements within the computer vision community. The application this is being tested on is by translating sign language to English, but other applications have been theorized.
